# Hi-Tech Health Hub

Build a single-page website for a diagnostic clinic called "Hi-Tech Health Care" with the tagline "Your Health Partner."

BRAND COLORS:

- Primary teal: #1C939B

- Accent green: #66B74E

- Use white/off-white backgrounds, teal for headings and primary buttons, green as a secondary accent (icons, highlights, small details)

LOGO: I'll upload the logo separately (transparent PNG) — use it in the header/navbar and footer.

PAGE STRUCTURE (single page, smooth-scroll anchor navigation):

1. HEADER / NAV

   - Logo on the left

   - Nav links: Home, Services, Health Packages, Contact (smooth scroll to sections)

   - Phone number visible in header, click-to-call on mobile

   - Sticky on scroll

2. HERO SECTION

   - Headline: "Your Health, Our Priority" (or similar warm, trustworthy line)

   - Subheadline mentioning accurate diagnostics, experienced technicians, and modern lab facilities

   - Two CTA buttons: "Call Now" (tel: link) and "View Services" (scrolls to services)

   - Clean medical/diagnostic feel — not stock-photo generic, use icons or a subtle illustration in brand colors if no real photo is provided

3. SERVICES SECTION (grid/cards, one per service)

   - Lab Tests — all types of lab testing available

   - Digital X-Ray

   - Home Collection Facility — samples collected from home

   - Health Packages — multiple package tiers available

   - Online Report Access — view reports online

   - Experienced Technicians — skilled, trained staff

   Each card: icon, title, one-line description

4. COMING SOON SECTION

   - Clearly marked "Coming Soon" badge/ribbon

   - Scanning Services (ultrasound/imaging) — launching soon, equipment arriving shortly

   - Keep this visually distinct (slightly muted or with a "Coming Soon" tag) so it doesn't look like an active service

5. WORKING HOURS + LOCATION

   - Hours: 6 AM – 10 PM, all days

   - Address: Near Thaluk Hospital, Galaxy Mall, Mannarkad

   - Embed a simple map placeholder or Google Maps embed if location coordinates are added later

6. CONTACT SECTION

   - Two phone numbers, click-to-call: 90 61 40 00 41 / 90 61 40 00 42

   - WhatsApp click-to-chat button linking to one of the numbers

   - Simple contact form (name, phone, message) — no backend needed yet, just UI

7. FOOTER

   - Logo, tagline, working hours, phone numbers, address, copyright line

DESIGN REQUIREMENTS:

- Fully responsive, mobile-first (most visitors will be on phones)

- Clean, professional healthcare aesthetic — plenty of white space, rounded cards, soft shadows

- Fast-loading, minimal unnecessary animation

- Use Tailwind CSS

- Accessible color contrast (teal on white, not light-on-light)
