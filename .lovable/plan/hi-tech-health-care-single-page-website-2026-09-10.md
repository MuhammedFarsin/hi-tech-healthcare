# Hi-Tech Health Care single-page website

## Build
- Replace the placeholder home screen with a mobile-first clinic website using the supplied logo and brand colors.
- Add a sticky header with smooth-scroll links, visible phone access, and a compact mobile navigation menu.
- Create the hero, six service cards, visually muted coming-soon scanning section, working-hours/location section, contact details, WhatsApp link, contact form UI, and full footer.
- Use clinic-specific English copy, accessible labels, semantic sections, click-to-call links, and a map placeholder ready for future coordinates.

## Visual direction
- Clean off-white canvas with teal headings and actions, green highlights, restrained medical line icons, rounded cards, and soft shadows.
- Keep motion minimal and honor reduced-motion preferences.
- Preserve strong contrast and generous spacing on phone and desktop layouts.

## Assets and metadata
- Store the uploaded transparent logo through the project asset flow and use a padded square copy as the browser icon.
- Add clinic-specific page title, description, Open Graph, and social metadata.

## Verification
- Check the finished page at mobile and desktop sizes, including menu, anchor links, phone/WhatsApp links, form layout, and visual overflow.
